# Facial Emotion Recognition Using Deep Learning

## Overview

This project focuses on facial emotion recognition using deep learning and transfer learning. It explores deep learning models to classify facial expressions.

## Objectives

- Explore deep learning for facial emotion recognition.
- Experiment with transfer learning.
- Compare ResNet50 and VGG16.
- Develop an interactive application using Streamlit.

## Technologies

- Python
- TensorFlow and Keras
- OpenCV
- Streamlit
- ResNet50
- VGG16

## Features

- Facial emotion recognition from images.
- Face detection using OpenCV.
- Display of predicted emotions and confidence scores.
- Webcam support, if implemented in the project.
